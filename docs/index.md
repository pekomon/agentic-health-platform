# Agentic Health Platform

Agentic Health Platform is an experimental health and training platform
exploring production-oriented agentic engineering, reusable health-data SDKs,
MCP-based tool use, and evidence-backed training recommendations.

The first milestone focuses on generating a grounded daily training
recommendation using authorized Oura health data together with explicit user
goals and current context.

## Project goals

The project explores:

- reusable health-data integrations and SDK boundaries
- normalized health and training data
- MCP-based agent tool use
- structured, evidence-backed recommendations
- testable and observable agent workflows
- privacy-aware health-data handling
- future iOS, Android, and web clients

The initial implementation is intentionally narrow and single-user.

## Current scope

The first version will use recent Oura data to produce a daily training
recommendation through a command-line interface.

The recommendation may consider factors such as:

- sleep and recovery
- recent training history
- the user's training goal
- allowed training types
- available training time
- current local time and usual bedtime

The project is intended for wellness and training guidance only.

It is not a medical device and does not provide medical diagnosis or treatment.
