# Privacy Policy

Agentic Health Platform is an experimental software project for health and
training guidance.

## Data access

The application may access health and wellness data authorized by the user
through supported health data providers such as Oura.

Only data required for the application's enabled features is requested.

## Data use

Authorized health data is used to provide health and training-related features,
such as evidence-backed daily training recommendations.

The application is not intended for medical diagnosis or treatment.

## Data storage

During development, authorized data may be processed and stored locally for the
purpose of providing application functionality, testing integrations, and
calculating health trends or baselines.

Real user health data is not included in the project's public source code or
test fixtures.

## Third-party services

The application may use third-party infrastructure or AI services where
permitted by the relevant data provider's terms and applicable privacy
requirements.

The application's handling of provider data is subject to the terms applicable
to that provider.

## Data retention and deletion

Data is retained only as necessary for the application's functionality and may
be removed when it is no longer required.
